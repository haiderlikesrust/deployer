deployer is a tiny PaaS that lives on your server. It clones your Git repo, figures out how to build it, runs it in a container, and puts it live on your domain with automatic HTTPS — websites, APIs, bots and workers alike. No YAML rituals. No per-project server config. Ever.

Everything a one-person platform needs

The features you'd reach for on Vercel or Railway — running on hardware you own, for apps you own.

🔍

Zero-config builds

A Dockerfile is used if present; otherwise the stack is detected — Node, Python, static sites — and a clean production Dockerfile is generated and shown in the build log.

🤖

Bots & workers, first-class

Not every deploy is a website. Repos without a web framework run as workers — no fake health checks, no dead URLs, crash alerts straight to your phone.

🔐

Automatic HTTPS

Every app gets name.yourdomain.com with a Let's Encrypt certificate. Custom domains are one field. Wildcard DNS once, never again.

⚡

Push to deploy

A GitHub webhook with HMAC verification deploys every push to your branch. Or curl one URL from anywhere — CI, cron, a Raspberry Pi.

🛟

Deploys that can't hurt you

New versions must pass a health gate before traffic switches. Failed builds never touch what's live. One-click rollback re-runs the previous image in seconds.

🧩

.env.example, understood

deployer reads your env example file, knows which keys are required, and asks you to fill them in before building — instead of crashing at 2am.

📟

Live logs & history

Streaming build logs, runtime logs, deployment history with commit messages and durations — and the exact resolved config of every deploy, source-labelled.

📣

Telegram & Discord alerts

Deploy succeeded, deploy failed, app crash-looping, missing env vars — pushed to your phone the moment they happen.

🗂

Monorepos

Point an app at any subdirectory. Deploy one repo five times as five apps — frontend, API, worker, docs, landing page.

How it works

Two containers on your VPS. Traefik owns the ports, deployer owns the workflow, your apps own the traffic.

  1. Install once. One command audits your VPS, sets up Traefik + deployer, and prints your dashboard URL and password.
  2. Point DNS. An A record and a wildcard. That's the last DNS you'll configure.
  3. Paste a repo. deployer clones, detects, builds an image, starts the container on a private network, and routes your domain to it.
  4. Push code. The webhook deploys every push. Health-gated swaps, retained images for rollback, old images pruned automatically.
git push→ webhook→ build→ health gate→ live + TLS

Install in one line

Ubuntu/Debian VPS, 2 GB RAM recommended. No domain yet? It offers you an sslip.io address so you can deploy in minutes.

curl -fsSL https://raw.githubusercontent.com/haiderlikesrust/deployer/main/install/install.sh \
  | sudo bash -s -- --base-domain yourdomain.com --email you@yourdomain.com
